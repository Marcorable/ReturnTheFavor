# ADR 0001: MVP SQLite 접근 방식

- 상태: 채택
- 결정: `expo-sqlite` API와 명시적 SQL을 사용한다.

## 배경

MVP의 데이터 모델과 마이그레이션 규칙은 아직 변경 가능성이 크다. 보답 완료·취소와 연결된 기록 삭제는 SQLite 트랜잭션과 외래 키 동작을 명확하게 검증해야 한다.

## 결정 이유

- `PRAGMA user_version` 기반 순차 마이그레이션과 트랜잭션 경계를 코드에 드러낼 수 있다.
- 현재 규모에서는 ORM의 추가 코드 생성·빌드 설정보다 저장소 인터페이스와 통합 테스트가 더 중요하다.
- 향후 Supabase를 도입해도 SQLite와 Postgres의 마이그레이션과 동기화 규칙은 별도로 관리해야 한다.

## 재검토 조건

스키마가 안정되고 복잡한 조합 쿼리가 늘어나거나, 타입 안전한 쿼리 작성의 유지보수 효과가 Drizzle의 추가 비용보다 커질 때 다시 평가한다.
